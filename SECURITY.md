# Security policy

## Supported versions

Nuxt Atelier is pre-1.0. Only the latest release gets security fixes.

## Reporting a vulnerability

**Don't open a public issue, discussion or PR.**

Report it privately through GitHub: go to the repository's **Security** tab and choose **Report a vulnerability** ([direct link](https://github.com/AnoRebel/nuxt-atelier/security/advisories/new)). Include:

- the affected package and version
- what an attacker can do, and under which configuration
- steps or a proof of concept to reproduce it

You'll get an acknowledgement within 7 days. Once the issue is confirmed, we'll agree on a disclosure date with you, publish a fix and a GitHub security advisory, and credit you unless you'd rather stay anonymous.
