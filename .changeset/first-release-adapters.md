First release: sign-in through Better Auth, media storage on S3-compatible services and Vercel Blob, and choosing nuxt-i18n-micro or @nuxtjs/i18n for the site's localized URLs. AI assist on any AI SDK provider: suggestions editors review (rewrite, translate, SEO, alt text), an assistant whose proposed requests the user approves and sends as themselves, exclusions, limits and a usage report. The visual editor: the real page in a frame rendering unsaved edits, selection in sync with the block structure and forms, in-place text editing, undo and redo, keyboard moves.
