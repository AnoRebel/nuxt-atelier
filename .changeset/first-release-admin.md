First release of the admin: a client-only route in a shadow root, built on crystal-neuo, with first-run setup, sign-in (passkeys and OAuth providers), collection lists with bulk actions, generated edit forms for every field type, users and roles, a dashboard, unsaved-change recovery, branding and appearance per viewer, overrides by name and custom pages, on headless composables. The layer installs it with an admin home to make your own.
