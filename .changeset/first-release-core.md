First release: content types (collections, singletons, routable pages) defined in TypeScript, block components registered from `defineBlock()`, migrations for SQLite, libSQL, D1, Postgres, MySQL and MariaDB, drafts, history, scheduling and background jobs, media with image variants, the built-in sign-in with passkeys, a typed content API with OpenAPI, server-rendered page metadata and JSON-LD, localized collections, reusable content (shared blocks, patterns, entry templates), several sites from one deployment (by host, with per-site content, media, search, sitemaps, tokens and roles), public forms (the form block, private uploads, spam protection with Turnstile, submissions with export and erasure), editorial collaboration (edit locks, presence, comments, notifications over WebSocket with a polling fallback, email through SMTP, Resend or Postmark), health endpoints, structured logs and security headers.
