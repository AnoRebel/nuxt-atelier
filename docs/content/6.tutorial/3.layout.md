Every page gets a header (the logo, the menu, the dark mode switch) and a footer (a copyright line, social links). What they show is content editors change, kept in one place: a **settings** singleton.

## Settings

A singleton without a route is content that no URL shows by itself: pages read it.

<!-- file: server/atelier/singletons/settings.ts -->
```ts [server/atelier/singletons/settings.ts]
import { defineSingleton, repeater, select, text } from '#atelier/server'

// What every page shows: the menu, the footer and where the blog lives
export default defineSingleton({
  label: 'Settings',
  admin: { icon: 'settings' },
  fields: {
    menu: repeater({
      label: 'Menu',
      fields: { label: text({ required: true }), link: text({ required: true, help: 'A path on the site (/about) or a web address' }) },
    }),
    copyrightText: text({ required: true, label: 'Copyright text' }),
    socialMedia: repeater({
      label: 'Social media',
      fields: {
        icon: select({ required: true, options: [{ value: 'github', label: 'GitHub' }, { value: 'x', label: 'X' }, { value: 'discord', label: 'Discord' }] }),
        link: text({ required: true }),
        title: text({ help: 'Shown on hover' }),
      },
    }),
  },
})
```

`useAtelierSingleton('settings')` reads it, with SSR, once per page however many components ask. The menu marks the current page with a dot that follows the pointer, and becomes a full-screen overlay on small screens:

<!-- file: app/components/SiteMenu.vue -->
```vue [app/components/SiteMenu.vue]
<!-- The menu from the settings: a dot follows the pointer on wide screens; a full-screen overlay on small ones -->
<script setup lang="ts">
const { data: settings } = await useAtelierSingleton('settings')
const menu = computed(() => settings.value?.data.menu ?? [])
const visible = useMobileMenuVisible()
const route = useRoute()
const items = ref<HTMLElement[]>([])
const dot = ref<number | null>(null)
const active = computed(() => menu.value.findIndex(({ link }) => link === '/' ? route.path === '/' : route.path === link || route.path.startsWith(`${link}/`)))
function moveDot(index = active.value) {
  dot.value = index > -1 && items.value[index] ? items.value[index].offsetLeft : null
}
onMounted(() => {
  moveDot()
  document.fonts.ready.then(() => moveDot()) // the menu's width changes once its font has loaded
  addEventListener('resize', () => moveDot())
})
watch(active, () => moveDot())
</script>

<template>
  <nav
    v-if="menu.length"
    aria-label="Main"
    class="relative tp:fixed tp:inset-0 tp:z-20 tp:flex tp:overflow-y-auto tp:bg-white/75 tp:backdrop-blur tp:transition-all tp:duration-300 tp:dark:bg-heading/80"
    :class="{ 'tp:invisible tp:opacity-0': !visible }"
  >
    <ul
      class="flex gap-15 tp:m-auto tp:flex-col tp:p-6 tp:text-center"
      @mouseleave="moveDot()"
    >
      <li
        v-for="({ label, link }, i) of menu"
        :key="link"
        ref="items"
      >
        <NuxtLink
          :to="link"
          class="text-sm font-bold text-heading transition dark:text-white"
          :class="{ 'tp:underline tp:decoration-2 tp:underline-offset-4': i === active }"
          @click="visible = false"
          @mouseenter="moveDot(i)"
        >
          {{ label }}
        </NuxtLink>
      </li>
    </ul>
    <span
      v-if="dot !== null"
      class="absolute top-1/2 mt-px -ml-3.5 size-1.5 rounded-full bg-heading transition duration-300 tp:hidden dark:bg-white"
      :style="{ transform: `translate3d(${dot}px, -50%, 0)` }"
    />
  </nav>
</template>
```

## Dark mode

A visitor's choice is a cookie, so the server renders the page in it and nothing flashes on load. Until they choose, the stylesheet follows their system (the `dark` variant from [chapter 1](/tutorial/setup)).

![The home page in dark mode: the header with the menu and the switch, the intro and the gallery](/media/tutorial-dark.webp)

<!-- file: app/composables/useColorScheme.ts -->
```ts [app/composables/useColorScheme.ts]
// Light or dark, as the visitor chose it (a cookie, so the server renders it: no flash), else as their
// system is (CSS alone, see main.css).
export function useColorScheme() {
  const choice = useCookie<'light' | 'dark' | null>('color-scheme', { default: () => null, maxAge: 60 * 60 * 24 * 365, sameSite: 'lax' })
  useHead({ htmlAttrs: { class: computed(() => choice.value ?? '') } })
  /** Dark now: the choice, or (with none, in the browser) the system's. */
  const isDark = computed(() => choice.value ? choice.value === 'dark' : import.meta.client && matchMedia('(prefers-color-scheme: dark)').matches)
  const toggle = () => choice.value = isDark.value ? 'light' : 'dark'
  return { choice, isDark, toggle }
}
```

<!-- file: app/components/DarkModeSwitch.vue -->
```vue [app/components/DarkModeSwitch.vue]
<!-- The sun and moon turn half a circle with each switch -->
<script setup lang="ts">
const { isDark, toggle } = useColorScheme()
const turns = ref(0)
const start = ref(0)
onMounted(() => start.value = isDark.value ? 180 : 0)
</script>

<template>
  <div class="relative size-5">
    <ClientOnly>
      <button
        type="button"
        class="absolute inset-0"
        :title="isDark ? 'Switch to light mode' : 'Switch to dark mode'"
        @click="toggle(); turns++"
      >
        <span
          class="absolute bottom-0 left-0 size-9 transition duration-300"
          :style="{ transform: `rotate(${start + turns * 180}deg)` }"
        >
          <IconSun
            class="absolute bottom-0 left-0 text-heading transition duration-300 dark:text-white"
            :class="isDark ? 'size-4 opacity-25' : 'size-5'"
          />
          <IconMoon
            class="absolute top-0 right-0 text-heading transition duration-300 dark:text-white"
            :class="isDark ? 'size-5 -rotate-180' : 'size-4 opacity-25'"
          />
        </span>
      </button>
    </ClientOnly>
  </div>
</template>
```
