## Posts

Posts are another collection, at `/blog/<slug>`, shown in their own layout. A post's content is text and images only: `allow` keeps other blocks out.

<!-- file: server/atelier/collections/posts.ts -->
```ts [server/atelier/collections/posts.ts]
import { blocks, date, defineCollection, media, slug, text, textarea } from '#atelier/server'

// Blog posts at /blog/<slug>, in their own layout
export default defineCollection({
  versioned: true,
  route: { pattern: '/blog/{slug}', layout: 'post' },
  admin: { icon: 'pin', columns: ['title', 'publishedOn'] },
  fields: {
    title: text({ required: true }),
    slug: slug({ from: 'title', required: true }),
    headline: text({ help: 'Shown as the post\'s heading; the title when empty' }),
    description: textarea({ help: 'The summary in the blog\'s list' }),
    cover: media({ help: 'The image in the blog\'s list' }),
    author: text(),
    publishedOn: date({ required: true, label: 'Published on' }),
    content: blocks({ allow: ['Image', 'Prose'] }),
  },
})
```

The `post` layout heads each post with a link back to the blog, its headline (editable in place) and when it was written. Where the blog is comes from the settings, which get a field for it:

<!-- file: server/atelier/singletons/settings.ts -->
```ts [server/atelier/singletons/settings.ts]
import { defineSingleton, repeater, select, text } from '#atelier/server'

// What every page shows: the menu, the footer and where the blog lives
export default defineSingleton({
  label: 'Settings',
  admin: { icon: 'settings' },
  fields: {
    menu: repeater({
      label: 'Menu',
      fields: { label: text({ required: true }), link: text({ required: true, help: 'A path on the site (/about) or a web address' }) },
    }),
    copyrightText: text({ required: true, label: 'Copyright text' }),
    socialMedia: repeater({
      label: 'Social media',
      fields: {
        icon: select({ required: true, options: [{ value: 'github', label: 'GitHub' }, { value: 'x', label: 'X' }, { value: 'discord', label: 'Discord' }] }),
        link: text({ required: true }),
        title: text({ help: 'Shown on hover' }),
      },
    }),
    blogPath: text({ required: true, label: 'Blog page', help: 'The page listing the posts: the back link on each post goes there' }),
  },
})
```

## The list of posts

The blog's page is a page like About, with a **Posts** block: the newest posts first, three at a time, with links to the next and previous pages (`?page=2`). `useAtelierQuery` reads them with SSR; each comes with its URL (`post.path`) and its media. A page past the last answers 404.

<!-- file: app/blocks/Posts.vue -->
```vue [app/blocks/Posts.vue]
<!-- The blog: newest posts first, three a page (?page=2…) -->
<script setup lang="ts">
import { defineBlock } from '#atelier'

defineBlock({ label: 'Posts', icon: 'list', description: 'The blog\'s posts, newest first' })
const PER_PAGE = 3
const route = useRoute()
const page = computed(() => Math.max(1, Number(route.query.page) || 1))
const { data } = await useAtelierQuery('posts', computed(() => ({ sort: ['-publishedOn'], limit: PER_PAGE, offset: (page.value - 1) * PER_PAGE })))
const lastPage = computed(() => Math.max(1, Math.ceil((data.value?.total ?? 0) / PER_PAGE)))
if (page.value > lastPage.value)
  throw createError({ statusCode: 404, statusMessage: 'No such page of posts' })
</script>

<template>
  <SiteContainer class="space-y-23">
    <article
      v-for="post of data?.items"
      :key="post.id"
      class="flex items-center gap-8 tp:flex-col"
    >
      <AtelierPicture
        v-if="post.data.cover && post.media?.[post.data.cover]"
        :media="post.media[post.data.cover]!"
        ratio="16:9"
        sizes="(max-width: 1023px) 100vw, 23.75rem"
        class="w-95 shrink-0 tp:w-full [&_img]:h-auto [&_img]:w-full [&_img]:rounded-md"
      />
      <div class="flex-1">
        <h2>
          <NuxtLink :to="post.path!">
            {{ post.data.headline || post.data.title }}
          </NuxtLink>
        </h2>
        <WrittenOn
          :author="post.data.author"
          :date="post.data.publishedOn"
          class="mt-2 text-vs"
        />
        <div
          v-if="post.data.description"
          class="prose mt-4"
        >
          <p>{{ post.data.description }}</p>
        </div>
        <SiteButton
          :to="post.path!"
          class="mt-6"
        >
          Read more
        </SiteButton>
      </div>
    </article>
    <nav
      v-if="lastPage > 1"
      aria-label="Pages of posts"
      class="flex gap-8"
    >
      <SiteButton
        v-if="page > 1"
        :to="`${route.path}?page=${page - 1}`"
      >
        Previous page
      </SiteButton>
      <SiteButton
        v-if="page < lastPage"
        :to="`${route.path}?page=${page + 1}`"
        class="ml-auto"
      >
        Next page
      </SiteButton>
    </nav>
  </SiteContainer>
</template>
```

## Try it

Create a few **Posts**, each with a cover image, a description, a date, and **Image** and **Text** blocks. Then create the page "Blog" with a **Page intro** and the **Posts** block, and set the blog's page to `/blog` in **Settings**.
