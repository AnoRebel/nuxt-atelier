The home page is one of a kind. Other pages (About, the blog's page, Contact) are entries of a **collection**, each at its own URL.

## Pages

`route: { pattern: '/{slug}' }` serves each page at its slug, made from the title as editors type it. `versioned: true` gives pages drafts: editors save and preview changes, and visitors see them once they're published. A page can also ask for a border above the footer.

<!-- file: server/atelier/collections/pages.ts -->
```ts [server/atelier/collections/pages.ts]
import { blocks, boolean, defineCollection, slug, text } from '#atelier/server'

// Pages at /<slug>: About, Blog (with the Posts block)…
export default defineCollection({
  versioned: true,
  route: { pattern: '/{slug}' },
  admin: { columns: ['title', 'slug'] },
  fields: {
    title: text({ required: true }),
    slug: slug({ from: 'title', required: true }),
    footerBorder: boolean({ label: 'Border above the footer' }),
    content: blocks(),
  },
})
```

The default layout draws that border when the page asks:

<!-- file: app/layouts/default.vue -->
```vue [app/layouts/default.vue]
<script setup lang="ts">
// a page may ask for a border above the footer
const { data } = useAtelierRouteEntry()
const border = computed(() => !!(data.value?.entry.data as { footerBorder?: boolean } | undefined)?.footerBorder)
</script>

<template>
  <div>
    <SiteHeader class="mt-12" />
    <main class="my-23 space-y-23">
      <slot />
      <hr
        v-if="border"
        class="border-border dark:border-white/10"
      >
    </main>
    <SiteFooter class="mb-23" />
  </div>
</template>
```

## Text and images

The **Text** block is rich text: editors format it in the admin, or right on the page in the visual editor. It's stored as a document, never HTML, and `<AtelierRichText>` renders it; `field="text"` lets the visual editor edit it in place.

<!-- file: app/blocks/Prose.vue -->
```vue [app/blocks/Prose.vue]
<script setup lang="ts">
import { defineBlock, richText } from '#atelier'

defineBlock({ label: 'Text', icon: 'pilcrow' })
defineProps({ text: richText({ required: true }) })
</script>

<template>
  <SiteContainer class="content-block">
    <AtelierRichText
      :value="text"
      field="text"
      class="prose max-w-content"
    />
  </SiteContainer>
</template>
```

<!-- file: app/blocks/Image.vue -->
```vue [app/blocks/Image.vue]
<script setup lang="ts">
import { defineBlock, media } from '#atelier'

defineBlock({ label: 'Image', icon: 'image' })
const props = defineProps({ image: media({ required: true }) })
const { data } = useAtelierRouteEntry()
const item = computed(() => props.image ? data.value?.media?.[props.image] : undefined)
</script>

<template>
  <SiteContainer class="content-block">
    <AtelierPicture
      v-if="item"
      :media="item"
      sizes="(max-width: 48.75rem) 100vw, 48.75rem"
      class="block h-auto w-full max-w-content overflow-hidden rounded-md [&_img]:h-auto [&_img]:w-full"
    />
  </SiteContainer>
</template>
```

## Try it

In **Pages**, create "About": a **Page intro**, an **Image**, and a **Text** block or two. Turn on the border above the footer, and publish. It's at `/about`, as the menu already says. Try the **Visual editor** on it: double-click the text to edit it on the page.
