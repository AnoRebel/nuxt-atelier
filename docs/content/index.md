# Nuxt Atelier

A visual CMS for Nuxt that you add to an existing app as a module: typed content schema, block-based visual editor, and an admin dashboard, with your pages, layouts and `app.vue` left alone.

::callout{icon="i-lucide-construction" color="warning"}
Nuxt Atelier is in early development and not released yet.
::
