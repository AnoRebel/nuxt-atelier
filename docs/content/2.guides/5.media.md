title: Images and files
description: Uploading images, videos and documents, describing them, finding them again, and removing them safely.
---

The media library holds your site's images, videos, audio and PDFs. Upload a file once, and use it on as many pages as you like.

## Uploading

Drop files into the library, or upload one straight from the field or block that needs it. Large files go up in pieces: if your connection drops, the upload picks up where it stopped instead of starting over.

The site checks what each file really is, not just its name: images, videos, audio and PDFs are accepted by default. A file pretending to be something else, like a program renamed `photo.jpg`, is refused. There's also a size limit, 50 MB unless your developer changed it.

## Describing a file

Each file has:

- **Alt text**: what the image shows, for people using screen readers and when the image can't load. Write what matters on the page, like "Ada presenting at the spring meetup", not "image". On a site in several languages, write it in each.
- **Title, caption and credits**: shown where your site's design uses them. Credits are for the photographer or source.
- **Folder and tags**: for finding it again. Folders hold each file in one place, like `team` or `events/2026`; tags let one file belong to several groups, like `team` and `portrait`.
- **Focal point**: the part of the image that must stay in view. When the site crops an image, to a square for a thumbnail for example, it keeps that point inside. Set it on the subject: a face, a product.

## Finding files

Search the library by name, title, caption or credits, or narrow it to a folder, a tag or a kind of file. Searching for the tag `team` shows only the files tagged `team`.

## Private files

Mark a file **private** to keep it off the public site: only people signed in to the CMS can open it. Use it for documents meant for the team. Don't add a private file to a public page, since visitors won't see it.

## Images on the site

You upload one image; the site makes the sizes it needs. Phones get small versions, large screens sharper ones, in modern formats that load faster, and each crop keeps your focal point in view. You don't need to resize images before uploading them, though very large photos take longer to upload.

## Removing a file

The library knows where each file is used. If you delete one that's still on pages, the CMS lists those pages first and asks you to confirm: the pages would show nothing in its place. Replace it on those pages, or confirm if that's what you want.

Deleting a file removes it for good, with all its sizes.
