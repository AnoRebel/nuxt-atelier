## Shared blocks

A shared block is one block, kept in **Shared blocks**, that you place on as many pages as you like. Edit it there and publish it: every page that uses it shows the change, without editing each page. Pages show a shared block's published version; its draft only shows in previews.

![Reuse this block, opened on a selected gallery: a title, then Save as shared block or Save as pattern](/media/visual-editor-reuse.webp)

A shared block's page lists **where it's used**.

- **Detach** a shared block on one page to make it that page's own copy: you can then change it there without touching the others, and it no longer follows the shared block.
- **Deleting** a shared block that's still used asks you first to **Detach everywhere** (each page keeps a copy and looks the same) or **Remove everywhere** (it disappears from those pages, live ones included).

## Patterns

A pattern is a ready-made arrangement of blocks, a "Pricing section" or a "Team grid". Inserting one adds its blocks to the page as ordinary blocks: change them freely, nothing links back to the pattern. Your developers can provide patterns, and you can save your own in **Patterns**.

## Templates

When you create an entry, **Start from** offers its templates: the entry starts with their blocks and field values instead of empty. Save any entry as a template with **Save as template**; the template keeps its values as they are now, and later changes to the entry don't affect it.
