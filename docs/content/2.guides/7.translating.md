---
title: Translating content
description: For editors, working with content in several languages in the admin.
---

When a site has more than one content locale (say English and German), some types are **localized**: each entry has a version per language, linked as translations. Each version has its own drafts, history, address and publishing, so the German page can go live before or after the English one.

## Find the version you want

A localized collection's list shows one language at a time. Pick it in **Locale** above the list. A new entry is created in the language the list shows.

Site-wide content (a home page, a banner) can be localized too. Its form says which language you're editing, with a link to each of the others; each language is saved and published on its own, and one left empty shows the default language's text on the site.

## Add a translation

Open the entry. Above its form you see its language (**In EN**) and the others:

- a language it has links to that version, like **DE**;
- a language it lacks shows **Add DE**, if your role may create entries.

**Add DE** creates the German version filled in with the English text, so you translate in place, field by field, then save it as a draft and publish it when it's ready.

## Fields the same in every language

Some fields aren't translated: a product code or a price, say. They're **shared**: changing one in any language changes it in all of them, each version getting a new revision. Your developers decide which fields these are.

## What visitors see in a language that lacks something

When a page has no German version yet, a German visitor gets the version your site falls back to (often English). When the German version leaves a field empty, that field comes from the fallback language too. Your developers set the fallback order.

## The admin's own language

The language of the admin's buttons and menus is separate from your content's: choose it in **Appearance** (the palette button), under **Language**, when your site has more than one installed.
