title: Starter layer
description: The optional layer with overridable theme files.
---

`@nuxt-atelier/layer` is an optional [Nuxt layer](https://nuxt.com/docs/getting-started/layers) on top of the module. It adds files you can override by creating a file with the same path in your app. You don't need it: everything works with the module alone.

## Use the layer

```bash
bun add nuxt-atelier @nuxt-atelier/layer
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@nuxt-atelier/layer'],
})
```

The layer adds `nuxt-atelier` to `modules` itself, so you don't list it again.

## What it provides

| File | What it is |
|---|---|
| `app/components/AtelierTheme.vue` | the design tokens (`--at-*` CSS variables) for the admin and editor, scoped to a wrapper element so they never touch your site's styles |

The admin pages join the layer once the admin is released.

## Override a file

Create the same path in your app. For example, to replace the theme:

```vue [app/components/AtelierTheme.vue]
<template>
  <div class="at-theme">
    <slot />
  </div>
</template>

<style>
.at-theme {
  --at-color-primary: oklch(0.6 0.2 30);
  --at-radius: 0;
}
</style>
```

Your file is used instead of the layer's; the rest of the layer stays as it is.
