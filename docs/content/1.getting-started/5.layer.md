title: Starter layer
description: The optional layer with the admin and admin pages to make your own.
---

`@nuxt-atelier/layer` is an optional [Nuxt layer](https://nuxt.com/docs/getting-started/layers) on top of the module. It adds files you can override by creating a file with the same path in your app. You don't need it: everything works with the module alone.

## Use the layer

```bash
bun add nuxt-atelier @nuxt-atelier/layer
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@nuxt-atelier/layer'],
})
```

The layer adds `nuxt-atelier` and `@nuxt-atelier/admin` to `modules` itself, so you don't list them again.

## What it provides

| File | What it is |
|---|---|
| `app/atelier-admin/Home.vue` | the admin's home page, a starting point to make your own: plain Vue on the admin's [composables](/reference/admin#build-your-own-admin) |

## Override a file

Create the same path in your app. For example, to make the admin's home your own:

```vue [app/atelier-admin/Home.vue]
<script setup lang="ts">
const { items } = useAtelierNavigation()
</script>

<template>
  <section class="app-page">
    <h1 class="app-page__title">Newsroom</h1>
    <NuxtLink v-for="item in items" :key="item.to" :to="item.to">{{ item.label }}</NuxtLink>
  </section>
</template>
```

Your file is used instead of the layer's; the rest of the layer stays as it is. Any other part of the admin can be replaced the same way: see [replacing a part of the admin](/reference/admin#replace-a-part-of-the-admin).
