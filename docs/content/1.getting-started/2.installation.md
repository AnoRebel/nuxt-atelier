## Requirements

- Nuxt 4.6 or later, including Nuxt 5
- Node.js 22, 24 or 26

## Add the module

::code-group
```bash [nuxi]
npx nuxt module add nuxt-atelier
```
```bash [bun]
bun add nuxt-atelier
```
```bash [pnpm]
pnpm add nuxt-atelier
```
```bash [npm]
npm install nuxt-atelier
```
::

`nuxt module add` installs the package and adds it to `modules` for you. With a package manager, add it yourself:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-atelier'],
})
```

That's the whole install. Continue with the [quick start](/getting-started/quick-start).
