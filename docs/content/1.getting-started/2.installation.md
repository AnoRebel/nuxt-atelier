## Requirements

- Nuxt 4.6 or later, including Nuxt 5
- Node.js 22, 24 or 26

## Add the module

::code-group
```bash [nuxi]
npx nuxt module add nuxt-atelier
```
```bash [bun]
bun add nuxt-atelier
```
```bash [pnpm]
pnpm add nuxt-atelier
```
```bash [npm]
npm install nuxt-atelier
```
::

`nuxt module add` installs the package and adds it to `modules` for you. With a package manager, add it yourself:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-atelier'],
})
```

That's the whole install for SQLite. Continue with the [quick start](/getting-started/quick-start).

## Optional packages

Nuxt Atelier only installs what every app needs. Add these when you use the feature:

| Package | Needed for | Install as |
|---|---|---|
| `pg` | a PostgreSQL database (`postgres:` URL) | dependency |
| `mysql2` | a MySQL or MariaDB database (`mysql:` / `mariadb:` URL) | dependency |
| `drizzle-kit@1.0.0-rc.5` | generating migrations (`atelier migrate generate`) | dev dependency |
| `@simplewebauthn/server` | [passkey sign-in](/reference/authentication#passkeys) with the built-in auth | dependency |
| `@nuxt-atelier/auth-better-auth` and `better-auth` | [Better Auth](/reference/auth-adapters#better-auth): OAuth, two-factor and more | dependency |

### Why drizzle-kit is optional

Nuxt Atelier stores content through [Drizzle](https://orm.drizzle.team). Writing a migration means comparing your content schema with the last migration and producing the SQL for the difference. That comparison is what `drizzle-kit` does, and it's a large package with its own build tooling.

You only need it on the machine where you change the schema and generate migrations. Applying migrations (`atelier migrate apply`), checking them (`atelier migrate status`) and running the app need only `drizzle-orm`, which Nuxt Atelier installs. So drizzle-kit stays out of your production install, and out of apps that never change their schema.

Install the exact version Nuxt Atelier is tested with. Drizzle 1.0 is a release candidate, and its migration format may change between candidates:

```bash
npm install -D drizzle-kit@1.0.0-rc.5
```

If it's missing, `atelier migrate generate` stops and prints this command.
