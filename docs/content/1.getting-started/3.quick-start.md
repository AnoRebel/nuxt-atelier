---

With only `modules: ['nuxt-atelier', '@nuxt-atelier/admin']` and no options, Nuxt Atelier uses these defaults:

| | Default |
|---|---|
| Database | SQLite at `.data/atelier.sqlite` |
| Media storage | local files in `.data/uploads` |
| Authentication | built in |
| Admin | served at `/admin` |

Start your app as usual:

```bash
npx nuxt dev
```

Open `/admin`: the first visit asks for the first administrator's account.

Your own `app.vue`, layouts and pages keep working unchanged. Nuxt Atelier only handles paths your app doesn't already define.

## Going to production

Two settings usually differ in production. Set them as environment variables, so the same build runs everywhere:

```bash [.env]
NUXT_ATELIER_DATABASE_URL=postgres://cms:secret@db:5432/atelier
NUXT_APP_SECRET=a-long-random-string-of-at-least-32-characters
```

`NUXT_APP_SECRET` signs session cookies. Keep it secret and don't change it between deploys, or everyone gets signed out.

::note
`.data/` holds the SQLite database and uploads. Add it to `.gitignore`, and put it on a persistent volume if you deploy with SQLite.
::
