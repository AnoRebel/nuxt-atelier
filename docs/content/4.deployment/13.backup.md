---
title: Backup and moving databases
description: Export all content to a file, and import it into another instance or another database engine.
---

`atelier export` writes all content to one portable file; `atelier import` loads it into another instance. The file doesn't depend on the database engine, so it also moves content from SQLite to Postgres, or from Postgres to MySQL.

## What's in an export

- every entry of every collection, with its relations
- every singleton
- every revision
- routes
- users of the built-in sign-in, with their roles and password hashes

Sessions aren't included, so everyone signs in again after a restore. Media files aren't included either: back up your storage (a directory, a bucket) alongside the export.

::warning
An export holds password hashes: store it as you would the database itself.
::

## Export

```bash
npx atelier export backup.ndjson.gz
```

A name ending in `.gz` is compressed. The command reads the database URL from `NUXT_ATELIER_DATABASE_URL` or your `nuxt.config.ts`, and streams: a large site doesn't need memory to match its size.

```txt
Exported 675 rows:
  atelier_c_articles: 120
  atelier_relations: 240
  atelier_revisions: 310
  atelier_routes: 0
  atelier_singletons: 2
  atelier_users: 3
```

## Import

Import into an empty database whose tables exist:

```bash
NUXT_ATELIER_DATABASE_URL=postgres://cms@new-db:5432/atelier npx atelier migrate apply
NUXT_ATELIER_DATABASE_URL=postgres://cms@new-db:5432/atelier npx atelier import backup.ndjson.gz
```

An import:

- runs in one transaction: if any row fails, the database stays empty;
- refuses a database that already has content;
- refuses an export with content for collections your schema doesn't define, naming them.

## Moving to another engine

1. Export from the current database.
2. Install the new engine's driver (`pg` or `mysql2`), and generate its migrations if you haven't: `npx atelier migrate generate --dialect postgres`.
3. Apply them to the new database, then import.
4. Point `NUXT_ATELIER_DATABASE_URL` at the new database and rebuild, so the build includes the new driver.

## Scheduled backups

`atelier export` is a plain command, so any scheduler can run it. For example, a nightly cron job on the server:

```bash [crontab]
0 3 * * * cd /srv/site && npx atelier export /backups/atelier-$(date +\%F).ndjson.gz
```
