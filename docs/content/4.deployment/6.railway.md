[Railway](https://railway.com) builds your app from its repository and runs it next to a PostgreSQL database. The service, the database and a volume for uploads are described in `.railway/railway.ts`, Railway's infrastructure as code. It replaces `railway.json`, which Railway has deprecated.

## Build command and preset

The preset is Nuxt's default, the Node server. Railway builds with your package manager and runs `npm run build`, then starts `node .output/server/index.mjs` (`build` and `start` in `.railway/railway.ts`).

Railway's builder, Railpack, picks Node 22 unless told otherwise, and Nuxt Atelier needs Node 24 or newer. Pin it with the service variable `RAILPACK_NODE_VERSION=24`, a `.node-version` file (`24`), or `engines` in `package.json` (`"node": ">=24"`).

Install Railway's package, connect the service to your repository, set the secrets (below), and apply the file:

```bash
npm install -D railway
railway config plan    # shows what will change
railway config apply
```

Each push to the repository then deploys.

## Configuration files

<!-- file: railway/.railway/railway.ts -->
```ts [.railway/railway.ts]
// Nuxt Atelier on Railway: the app, a PostgreSQL database and a volume for uploads.
// Needs the railway package (npm install -D railway); `railway config apply` applies it.
import { defineRailway, postgres, preserve, project, service, volume } from 'railway/iac'

export default defineRailway(() => {
  const db = postgres('postgres')
  const uploads = volume('uploads', { sizeMB: 1024 })

  const web = service('web', {
    build: 'npm run build',
    start: 'node .output/server/index.mjs',
    healthcheck: '/api/_atelier/health/ready',
    volumeMounts: { '/data': uploads },
    env: {
      NUXT_ATELIER_DATABASE_URL: db.env.DATABASE_URL,
      NUXT_ATELIER_STORAGE_DIR: '/data/uploads',
      NUXT_ATELIER_MIGRATIONS_AUTO_APPLY: 'true',
      NUXT_ATELIER_AUTH_TRUST_PROXY: 'true',
      NUXT_APP_SECRET: preserve(),
      NUXT_PUBLIC_ATELIER_SITE_URL: preserve(),
      NUXT_ATELIER_AUTH_SETUP_TOKEN: preserve(),
    },
  })

  return project('my-site', { resources: [web, db, uploads] })
})
```

<!-- file: railway/nuxt.config.ts -->
```ts [nuxt.config.ts]
// Railway: Nuxt's default Node server, configured from the service's variables (.railway/railway.ts).
// PostgreSQL needs its driver in your app: npm install pg
export default defineNuxtConfig({
  modules: ['nuxt-atelier', '@nuxt-atelier/admin'],
  compatibilityDate: '2026-10-01',
})
```

PostgreSQL needs its driver in your app: `npm install pg`.

## Environment variables

The file sets them on the service. `preserve()` keeps a value you set in Railway's dashboard, so secrets stay out of the repository: set these in the service's variables before applying.

| Variable | Value |
|---|---|
| `NUXT_APP_SECRET` | at least 32 random characters (`openssl rand -hex 32`). The server won't start without it. |
| `NUXT_PUBLIC_ATELIER_SITE_URL` | the site's public URL |
| `NUXT_ATELIER_AUTH_SETUP_TOKEN` | first-run setup asks for it, so nobody else can become the first administrator |
| `NUXT_ATELIER_DATABASE_URL` | set from the database's `DATABASE_URL` |
| `NUXT_ATELIER_AUTH_TRUST_PROXY` | `true`: requests arrive through Railway's proxy |

## Database

PostgreSQL, the `postgres` service. Its `DATABASE_URL` becomes the app's `NUXT_ATELIER_DATABASE_URL`.

## Migrations on deploy

`NUXT_ATELIER_MIGRATIONS_AUTO_APPLY=true`: the server applies pending migrations when it starts. To apply them as a step instead, before the new version takes traffic, give the service `preDeploy: 'npx atelier migrate apply'` and remove the variable.

## Media storage

Uploads go to `/data/uploads`, on the `uploads` volume mounted at `/data`.

## Scheduled jobs

Background jobs run in the server process, on Nitro's scheduler, every minute by default. Nothing to set up.

## Real-time

The server serves the admin's WebSocket itself: edits, locks and comments are pushed to other editors at once.

## Limitations

| Limitation | Instead |
|---|---|
| A volume attaches to one service, so uploads can't be shared with another | [S3-compatible storage](/reference/media#s3-compatible-storage-and-cloudflare-r2) |
