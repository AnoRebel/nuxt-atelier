Forms are entries of the built-in `atelier-forms` collection (versioned: the site uses the published version), built by editors (see [Building forms](/guides/building-forms)). Submissions are stored in `atelier_form_submissions`; their table comes with your next `atelier migrate generate`.

## On a page

The **Form** block places one (when the app has blocks), or render it yourself:

```vue
<AtelierForm form="<form id>" locale="de" />
```

It renders plain, accessible markup with `atelier-form…` classes and no styles: style those. The browser checks the same rules the server checks again (one Valibot schema, `submissionSchema` from `#atelier/shared/forms`), with [TanStack Form](https://tanstack.com/form). To replace it entirely, add your own `AtelierForm` component (yours wins) on the same API:

| Request | |
|---|---|
| `GET /api/_atelier/forms/<id>?locale=de` | the published form: `title`, `fields` (labels in that locale), `submitLabel`, a `token`, and the `challenge` to show (or `null`) |
| `POST /api/_atelier/forms/<id>/submit` | the values, as JSON or `multipart/form-data` (with files), plus `_token`, `_hp` (the honeypot, empty), `_locale` and `_challenge`; answers `{ ok, message?, redirect? }`, or `422` with `errors: [{ path, message }]` and nothing stored |

## Spam and abuse

- **Rate limit**: [`forms.submissionsPerHour`](/reference/configuration#forms) per IP address and form, then `429`.
- **Honeypot**: `_hp` is a field people don't see. Filled in, the submission is dropped, answered as if it was sent.
- **Minimum fill time**: the token records when the form was loaded; a submission sooner than [`forms.minFillTime`](/reference/configuration#forms) seconds after (3 by default) is dropped the same way. A token older than a day, or not genuine, answers `400`.
- **Challenge**: set `NUXT_ATELIER_FORMS_TURNSTILE_SITE_KEY` and `NUXT_ATELIER_FORMS_TURNSTILE_SECRET` for [Cloudflare Turnstile](https://developers.cloudflare.com/turnstile/): the form shows its widget, and the server verifies the answer. Or bring your own provider:

```ts [server/plugins/challenge.ts]
import { registerChallengeAdapter } from '#atelier/server'

export default defineNitroPlugin(() => {
  registerChallengeAdapter(() => ({
    name: 'hcaptcha',
    siteKey: process.env.HCAPTCHA_SITE_KEY!,
    async verify(token, ip) {
      const response = await fetch('https://api.hcaptcha.com/siteverify', { method: 'POST', body: new URLSearchParams({ secret: process.env.HCAPTCHA_SECRET!, response: token, remoteip: ip }) })
      return (await response.json()).success === true
    },
  }))
})
```

`<AtelierForm>` renders Turnstile's widget itself; for another provider, render its widget in the `#challenge` slot and leave its answer in an input named `atelier-challenge`.

## Submissions

For roles with the `forms` [capability](/reference/permissions#a-role):

| Request | |
|---|---|
| `GET /api/_atelier/forms/<id>/submissions?q&from&to&limit&offset` | `{ fields, items, total }`, newest first; `q` finds text in any value |
| `GET …/submissions?format=csv` or `format=json` | every matching one, as a download; CSV cells starting like a formula are written as text |
| `DELETE …/submissions/<submission>` | deletes one, files included |
| `GET …/submissions/<submission>/files/<field>` | an uploaded file, as a download |
| `POST /api/_atelier/forms/erase` | `{ email }`: deletes every submission of any form with that address in an email field, files included; answers `{ deleted }` (audited as `forms.erased`) |

Each submission keeps the form's version it answered and its locale. Files go to your [storage](/reference/media) under `forms/<submission>/`, which no public URL serves. A daily job deletes submissions older than their form's `retentionDays`.

## Emails and events

After a submission is stored:

- the form's **notify** addresses get it by email, and the sender a **confirmation** when it's on, through [email](/reference/collaboration#email) as background jobs, retried on failure (nothing is sent until email is set up);
- the `atelier:formSubmitted` [hook](/reference/hooks) runs with `{ form, submission }`;
- [webhooks](/reference/webhooks) subscribed to `form.submitted` get `{ form, submission, version, locale, createdAt }`.

A failure in any of these is logged; the submission stands.
