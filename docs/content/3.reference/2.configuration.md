Options go under the `atelier` key in `nuxt.config.ts`. Every option is optional. Invalid values stop the build with a message naming the option, the value and what's accepted.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-atelier'],
  atelier: {
    database: { url: 'postgres://cms@localhost:5432/atelier' },
  },
})
```

## `database`

| Option | Type | Default | Description |
|---|---|---|---|
| `database.url` | string | `"file:.data/atelier.sqlite"` | Database URL: `file:` (SQLite), `libsql:` (libSQL/Turso), `d1:<binding>` (Cloudflare D1), `postgres:`, `mysql:` or `mariadb:`. Override at runtime with `NUXT_ATELIER_DATABASE_URL`. |

## `migrations`

| Option | Type | Default | Description |
|---|---|---|---|
| `migrations.autoApply` | boolean | `false` | Apply pending migrations when the production server starts. When off, run `atelier migrate apply`; until then CMS writes are refused. Override at runtime with `NUXT_ATELIER_MIGRATIONS_AUTO_APPLY`. |

## `media`

| Option | Type | Default | Description |
|---|---|---|---|
| `media.accept` | array | `["image/*","video/*","audio/*","application/pdf"]` | File types that may be uploaded, judged by their content: MIME types, with `type/*` for a whole family. Types only recognisable by name (SVG, plain text) can't be checked, so aren't accepted. |
| `media.widths` | array | `[320,640,960,1280,1920,2560]` | The widths image variants are made at (with `sharp` installed), and the only ones served: other sizes would let anyone fill your storage with variants. |
| `media.provider` | string | `undefined` | An image service that makes the variants instead of this server, for hosts without `sharp`: a URL template with `{src}` (the file's absolute URL), `{w}`, and optionally `{h}` (for a ratio), `{fx}` and `{fy}` (the focal point, 0–1). Cloudflare: `/cdn-cgi/image/width={w},height={h},fit=cover,gravity={fx}x{fy},format=auto/{src}`. |

## `locales`

| Option | Type | Default | Description |
|---|---|---|---|
| `locales.codes` | array | `["en"]` | The content locales. Types declared `localized` keep one version of each entry per locale. With one locale, the admin shows no translation controls. |
| `locales.default` | string | `undefined` | The default locale: new entries' locale when none is given, and the last fallback. The first of `locales.codes` when omitted. |
| `locales.fallback` | record | `{}` | Where reads look when an entry or a translated field is missing in the requested locale, per locale: `{ "de-at": ["de", "en"] }`. Every other locale falls back to the default locale. |

## `seo`

| Option | Type | Default | Description |
|---|---|---|---|
| `seo.titleTemplate` | string | `"%s"` | The title of CMS pages, `%s` standing for the page's own: `"%s · My site"`. |

## `i18n`

| Option | Type | Default | Description |
|---|---|---|---|
| `i18n.module` | `"auto"` \| `"nuxt-i18n-micro"` \| `"@nuxtjs/i18n"` \| `false` | `"auto"` | The i18n module whose locales and URL strategy the site's pages follow: `/de/produkte/stuhl` is the German entry at `/produkte/stuhl`. `auto` uses nuxt-i18n-micro when it's installed, otherwise @nuxtjs/i18n, otherwise none: locales then come from the `locale` query parameter only. |

## `storage`

| Option | Type | Default | Description |
|---|---|---|---|
| `storage.driver` | `"local"` \| `"s3"` \| `"vercel-blob"` | `"local"` | Where media files are stored: `local` (the server's disk, `storage.dir`), `s3` (S3-compatible storage and Cloudflare R2: install `@nuxt-atelier/storage-s3`) or `vercel-blob` (install `@nuxt-atelier/storage-vercel-blob`). |
| `storage.dir` | string | `".data/uploads"` | Upload directory, relative to the app root. Override at runtime with `NUXT_ATELIER_STORAGE_DIR`. |

## `auth`

| Option | Type | Default | Description |
|---|---|---|---|
| `auth.provider` | `"builtin"` | `"builtin"` | Authentication provider. |
| `auth.signInAttempts` | integer, 1–1000 | `10` | Failed sign-ins allowed per IP address and email within `auth.signInWindow`; then 429 until it ends. An email alone allows five times as many, so rotating addresses doesn't help. |
| `auth.signInWindow` | integer, 60–86400 | `900` | The sign-in rate limit window, in seconds. |
| `auth.trustProxy` | boolean | `false` | Take the client IP from `X-Forwarded-For`. Turn on only behind a proxy that sets it, or clients could spoof their address. |
| `auth.passkeys` | boolean | `false` | Let users of the built-in provider register passkeys and sign in with them. Needs `@simplewebauthn/server`. The relying party is the public site URL (`NUXT_PUBLIC_ATELIER_SITE_URL`). |

## `admin`

| Option | Type | Default | Description |
|---|---|---|---|
| `admin.base` | string | `"/admin"` | Path the admin is served under: a leading slash, no trailing slash, not under `/api`. |

## `revisions`

| Option | Type | Default | Description |
|---|---|---|---|
| `revisions.keep` | integer, 1–100000 | `50` | Revisions each entry keeps at least: its newest ones. Older ones are deleted once they're also older than `revisions.days`, except, in versioned types, those that were published. Checked daily, as a background job. |
| `revisions.days` | integer, 0–36500 | `30` | Days every revision is kept, however many there are. |

## `jobs`

| Option | Type | Default | Description |
|---|---|---|---|
| `jobs.schedule` | string \| `false` | `"* * * * *"` | When the server runs due background jobs, as a cron expression, with Nitro's scheduled tasks (Node, Bun, Deno; Vercel Cron and Cloudflare Cron Triggers at build, which take 5 fields). `false` leaves it to the trigger endpoint, for platforms without scheduled tasks. |
| `jobs.triggerBudget` | integer, 1–900 | `25` | Seconds the job trigger endpoint (`POST /api/_atelier/jobs/run`) keeps starting jobs; the rest stay queued for the next call. Its secret is `NUXT_ATELIER_JOBS_SECRET`. |

## `webhooks`

| Option | Type | Default | Description |
|---|---|---|---|
| `webhooks.allow` | array | `[]` | Hosts webhooks may reach even though they're internal (private, loopback or link-local addresses), e.g. a service on your own network. Override at runtime with `NUXT_ATELIER_WEBHOOKS_ALLOW` (a JSON list). |

## Runtime overrides

These take effect in a built app without rebuilding:

| Environment variable | Overrides |
|---|---|
| `NUXT_ATELIER_DATABASE_URL` | `database.url` |
| `NUXT_ATELIER_MIGRATIONS_AUTO_APPLY` | `migrations.autoApply` |
| `NUXT_ATELIER_STORAGE_DIR` | `storage.dir` |
| `NUXT_PUBLIC_ATELIER_SITE_URL` | the public site URL |
| `NUXT_APP_SECRET` | the session secret (Nuxt's `runtimeConfig.appSecret`) |
